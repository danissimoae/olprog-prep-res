# OlProg Prep

Русские условия задач [CSES](https://cses.fi/problemset/) и редактор кода с быстрой отправкой на CSES.
Легковесный сайт

## Дисклеймер

- Условия задач взяты с [CSES Problem Set](https://cses.fi) и принадлежат их автору (Antti Laaksonen). Переводы сделаны для личного обучения.
- Проект неофициальный и не связан с CSES. Решения проверяются на самом CSES.
- Всё остальное (код сайта, оформление) написано из энтузиазма, без гарантий и поддержки.
- Правообладатель может попросить убрать любую задачу: напишите в issue, удалю.

## Лицензия

Код сайта: [MIT](LICENSE). На условия задач (`problems/**/*.md`) лицензия не распространяется.

## Запуск

```
python -m http.server   # открыть http://localhost:8000
```

## Добавить задачу

1. Создать `problems/<тема>/<id>.md` с front matter (`id`, `title`, `titleRu`, `order`) и текстом в Markdown.
2. `node tools/build-index.mjs`
3. Новая тема: добавить её в `olprog-practice` и создать папку.

Есть сетка $7 \times 7$. Вы стартуете в левом верхнем углу и должны посетить каждую клетку ровно один раз, вернувшись в левый нижний угол.

Дана строка из 48 символов, описывающая путь: `D` — вниз, `U` — вверх, `L` — влево, `R` — вправо, `?` — неизвестный ход.

Подсчитайте количество путей, соответствующих описанию.

### Формат ввода

Одна строка длины 48.

### Формат вывода

Выведите количество путей.

### Пример

Ввод:
```
??????R??????U?????????????????????????LD???D?
```
Вывод:
```
201
```

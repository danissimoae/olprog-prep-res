Есть $n$ яблок с известными весами. Разделите их на две группы так, чтобы разница суммарных весов была минимальной.

### Формат ввода

Первая строка содержит $n$. Вторая строка — $n$ чисел $p_1, \dots, p_n$ — веса яблок.

### Формат вывода

Выведите минимальную разницу весов.

### Ограничения

- $1 \le n \le 20$
- $1 \le p_i \le 10^9$

### Пример

Ввод:
```
5
3 2 7 4 1
```
Вывод:
```
1
```

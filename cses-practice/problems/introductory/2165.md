Решите задачу Ханойской башни: есть три стержня и $n$ дисков разного размера на левом стержне (меньший сверху). Переместите все диски на правый стержень, соблюдая правила.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите минимальное число ходов, затем сами ходы (каждый ход: два числа — откуда, куда).

### Ограничения

- $1 \le n \le 16$

### Пример

Ввод:
```
2
```
Вывод:
```
3
1 2
1 3
2 3
```

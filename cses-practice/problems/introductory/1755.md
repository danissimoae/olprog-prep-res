Дана строка. Ваша задача — переставить её символы так, чтобы получился палиндром.

### Формат ввода

Одна строка из заглавных букв.

### Формат вывода

Выведите любой палиндром из символов исходной строки, или `NO SOLUTION`, если его не существует.

### Ограничения

- Длина строки от 1 до $10^6$

### Пример

Ввод:
```
AAAACACBA
```
Вывод:
```
AAACBCAAA
```

Дана строка. Выведите все строки, которые можно получить перестановкой её символов, в лексикографическом порядке.

### Формат ввода

Одна строка из букв.

### Формат вывода

Сначала выведите количество строк, затем сами строки по одной в строке.

### Ограничения

- Длина строки от 1 до 8

### Пример

Ввод:
```
aab
```
Вывод:
```
3
aab
aba
baa
```

Рассмотрим бесконечную последовательность цифр, образованную записью всех положительных целых чисел подряд:

$$123456789101112131415\dots$$

Для каждого запроса $k$ найдите цифру на позиции $k$.

### Формат ввода

Первая строка содержит $q$ — количество запросов.

Каждая из следующих $q$ строк содержит число $k$.

### Формат вывода

Для каждого запроса выведите искомую цифру.

### Ограничения

- $1 \le q \le 1000$
- $1 \le k \le 10^{18}$

### Пример

Ввод:
```
3
7
19
12
```
Вывод:
```
7
4
1
```

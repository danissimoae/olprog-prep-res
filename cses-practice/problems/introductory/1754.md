У вас есть две кучи монет. На каждом ходу вы можете убрать одну монету из левой кучи и две из правой, или две из левой и одну из правой.

Определите, можно ли сделать обе кучи пустыми.

### Формат ввода

Первая строка содержит $t$ — количество тестов.

Каждая из следующих $t$ строк содержит два числа $a$ и $b$ — размеры куч.

### Формат вывода

Для каждого теста выведите `YES` или `NO`.

### Ограничения

- $1 \le t \le 10^5$
- $0 \le a, b \le 10^9$

### Пример

Ввод:
```
3
2 1
2 2
3 3
```
Вывод:
```
YES
NO
YES
```

Есть $n$ книг, каждую из которых нужно прочитать за $t_i$ дней. Для каждой книги указан крайний срок $d_i$ — день, до которого её надо прочитать.

Вы читаете ровно одну книгу за раз. Какое минимальное общее опоздание возможно?

Опоздание для книги $i$ — это $\max(0, \text{день окончания} - d_i)$.

### Формат ввода

Первая строка содержит одно целое число $n$ — количество книг.

Каждая из следующих $n$ строк содержит два целых числа $t_i$ и $d_i$ — время чтения и крайний срок книги $i$.

### Формат вывода

Выведите одно число — минимальное общее опоздание.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le t_i, d_i \le 10^6$

### Пример

Ввод:
```
3
2 3
3 5
1 4
```
Вывод:
```
2
```

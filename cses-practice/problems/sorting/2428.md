Дан массив из $n$ целых чисел. Подсчитайте количество подмассивов, содержащих не более $k$ различных значений.

### Формат ввода

Первая строка содержит $n$ и $k$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите количество подмассивов с не более чем $k$ различными элементами.

### Ограничения

- $1 \le k \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
5 2
1 2 3 1 1
```
Вывод:
```
10
```

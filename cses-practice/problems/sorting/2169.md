Дано $n$ отрезков. Для каждого отрезка подсчитайте, сколько других отрезков он содержит, и сколько отрезков содержат его.

Отрезок $[a, b]$ содержит отрезок $[c, d]$, если $a \le c$ и $d \le b$.

### Формат ввода

Первая строка содержит $n$.

Каждая из следующих $n$ строк содержит два числа $x$ и $y$ — концы отрезка.

### Формат вывода

Выведите две строки по $n$ чисел: количество содержащих и содержащихся отрезков для каждого.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x < y \le 10^9$

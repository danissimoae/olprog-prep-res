Дан массив из $n$ положительных целых чисел. Подсчитайте количество подмассивов с суммой равной $x$.

### Формат ввода

Первая строка содержит $n$ и $x$.

Вторая строка содержит $n$ положительных чисел.

### Формат вывода

Выведите количество подмассивов с суммой $x$.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x, a_i \le 10^9$

### Пример

Ввод:
```
5 7
2 4 1 2 7
```
Вывод:
```
3
```

Есть $n$ задач, и каждая задача требует определенного времени для выполнения. Вы хотите выполнить все задачи и минимизировать общее время ожидания.

Общее время ожидания — это сумма для каждой задачи времени, прошедшего до её окончания.

### Формат ввода

Первая строка содержит одно целое число $n$ — количество задач.

Вторая строка содержит $n$ целых чисел $d_1, d_2, \dots, d_n$ — продолжительность каждой задачи.

### Формат вывода

Выведите одно число — минимальное общее время ожидания.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le d_i \le 10^6$

### Пример

Ввод:
```
3
3 2 1
```
Вывод:
```
6
```

Пояснение: выполнив задачи в порядке 1, 2, 3, получим время ожидания 1 + 3 + 6 = 10. А в порядке 3, 2, 1 получим 1 + 3 + 6 = 6.

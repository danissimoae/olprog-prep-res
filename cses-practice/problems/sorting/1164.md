В гостинице есть $n$ клиентов. Известны время прибытия и ухода каждого. Каждому клиенту нужно выделить комнату так, чтобы никакие два клиента не пересекались по времени в одной комнате.

Определите минимальное количество комнат и распределите клиентов.

### Формат ввода

Первая строка содержит $n$.

Каждая из следующих $n$ строк содержит два числа $a$ и $b$ — время прибытия и ухода.

### Формат вывода

Первая строка — минимальное количество комнат.

Вторая строка — $n$ чисел: номер комнаты для каждого клиента (в порядке ввода).

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le a < b \le 10^9$

### Пример

Ввод:
```
3
1 2
2 4
4 4
```
Вывод:
```
2
1 2 1
```

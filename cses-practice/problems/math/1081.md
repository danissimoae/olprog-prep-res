Дан массив из $n$ целых чисел. Найдите пару чисел из массива с наибольшим общим делителем (НОД).

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите максимальный НОД пары чисел.

### Ограничения

- $2 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^6$

### Пример

Ввод:
```
5
3 14 15 7 9
```
Вывод:
```
7
```

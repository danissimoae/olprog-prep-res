Треугольные числа — это числа вида $T_k = \frac{k(k+1)}{2}$.

Найдите минимальное количество треугольных чисел, сумма которых равна $n$.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите минимальное количество треугольных чисел.

### Ограничения

- $1 \le n \le 10^{18}$

### Пример

Ввод:
```
12
```
Вывод:
```
2
```

Пояснение: $12 = 6 + 6 = T_3 + T_3$.

Дано число $n$. Найдите наименьшее простое число, большее $n$.

### Формат ввода

Первая строка содержит $t$ — количество тестов.

Каждая из следующих $t$ строк содержит число $n$.

### Формат вывода

Для каждого теста выведите наименьшее простое $> n$.

### Ограничения

- $1 \le t \le 10^5$
- $1 \le n \le 10^{12}$

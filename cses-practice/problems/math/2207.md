Игра Гранди: есть куча из $n$ камней. На ходу игрок разбивает кучу на две непустые кучи разных размеров.

Определите победителя.

### Формат ввода

Первая строка содержит $t$ — количество тестов.

Каждая из следующих $t$ строк содержит $n$.

### Формат вывода

Для каждого теста выведите `first` или `second`.

### Ограничения

- $1 \le t \le 10^5$
- $1 \le n \le 10^6$

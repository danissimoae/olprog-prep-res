Вычислите $a^{b^c} \bmod (10^9 + 7)$.

### Формат ввода

Первая строка содержит $n$ — количество запросов.

Каждая из следующих $n$ строк содержит три целых числа $a$, $b$ и $c$.

### Формат вывода

Для каждого запроса выведите $a^{b^c} \bmod (10^9 + 7)$.

### Ограничения

- $1 \le n \le 10^5$
- $0 \le a, b, c \le 10^9$

### Пример

Ввод:
```
1
3 7 1
```
Вывод:
```
2187
```

Двое играют в игру с $n$ палочками. На ходу игрок может убрать от 1 до $k$ палочек. Проигрывает тот, кто не может сделать ход.

Определите, выигрывает ли первый игрок при оптимальной игре.

### Формат ввода

Первая строка содержит $t$ — количество тестов.

Каждая из следующих $t$ строк содержит $n$ и $k$.

### Формат вывода

Для каждого теста выведите `WIN` или `LOSE` для первого игрока.

### Ограничения

- $1 \le t \le 10^5$
- $1 \le n, k \le 10^9$

### Пример

Ввод:
```
3
4 2
5 3
7 4
```
Вывод:
```
WIN
LOSE
WIN
```

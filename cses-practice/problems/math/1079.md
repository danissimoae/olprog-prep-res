Вычислите биномиальный коэффициент $\binom{n}{k}$ по модулю $10^9 + 7$.

### Формат ввода

Первая строка содержит $q$ — количество запросов.

Каждая из следующих $q$ строк содержит два числа $n$ и $k$.

### Формат вывода

Для каждого запроса выведите $\binom{n}{k} \bmod (10^9 + 7)$.

### Ограничения

- $1 \le q \le 10^5$
- $0 \le k \le n \le 10^6$

### Пример

Ввод:
```
3
5 3
8 1
9 5
```
Вывод:
```
10
8
126
```

На рождественской вечеринке $n$ человек обмениваются подарками. Подсчитайте количество способов, при которых никто не получает свой собственный подарок (задача о беспорядках / дерangement).

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите количество способов по модулю $10^9 + 7$.

### Ограничения

- $1 \le n \le 10^6$

### Пример

Ввод:
```
4
```
Вывод:
```
9
```

Дана строка. Подсчитайте количество различных строк, которые можно получить перестановкой её символов.

### Формат ввода

Одна строка из букв.

### Формат вывода

Выведите количество различных перестановок по модулю $10^9 + 7$.

### Ограничения

- Длина строки от 1 до $10^6$

### Пример

Ввод:
```
aab
```
Вывод:
```
3
```

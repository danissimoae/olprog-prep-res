Подсчитайте количество корректных скобочных последовательностей длины $n$, которые содержат заданную строку как фиксированный префикс.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит префикс из символов `(` и `)`.

### Формат вывода

Выведите количество последовательностей по модулю $10^9 + 7$.

### Ограничения

- $1 \le n \le 10^6$

### Пример

Ввод:
```
6
((
```
Вывод:
```
5
```

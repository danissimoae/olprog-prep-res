Подсчитайте количество делителей числа $x$.

### Формат ввода

Первая строка содержит $n$ — количество запросов.

Каждая из следующих $n$ строк содержит одно целое число $x$.

### Формат вывода

Для каждого запроса выведите количество делителей $x$.

### Ограничения

- $1 \le n \le 10^5$
- $1 \le x \le 10^6$

### Пример

Ввод:
```
3
16
17
18
```
Вывод:
```
5
2
6
```

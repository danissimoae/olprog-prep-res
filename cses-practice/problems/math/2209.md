Ожерелье длины $n$ состоит из бусин $m$ различных цветов. Два ожерелья эквивалентны, если одно можно получить из другого поворотом.

Подсчитайте количество различных ожерелий.

### Формат ввода

Два числа $n$ и $m$.

### Формат вывода

Выведите количество ожерелий по модулю $10^9 + 7$.

### Ограничения

- $1 \le n, m \le 10^6$

### Пример

Ввод:
```
4 3
```
Вывод:
```
24
```

Есть $n$ монет в ряд. Двое игроков по очереди берут монету с одного из концов ряда. Побеждает тот, у кого сумма взятых монет больше.

Определите максимальную сумму, которую может гарантировать первый игрок.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел — номиналы монет.

### Формат вывода

Выведите максимальную сумму первого игрока.

### Ограничения

- $1 \le n \le 5000$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
4
4 5 1 3
```
Вывод:
```
8
```

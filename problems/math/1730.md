Игра Ним: есть $n$ кучек с $x_1, \dots, x_n$ камнями. Двое игроков по очереди берут любое ненулевое количество камней из одной кучи. Проигрывает тот, кто не может сделать ход.

Определите победителя при оптимальной игре.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите `first` или `second`.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
3
1 2 3
```
Вывод:
```
second
```

Есть лестница с $n$ ступенями, на $i$-й ступени $x_i$ шаров. Двое игроков по очереди перемещают любое количество шаров со ступени $i$ на ступень $i-1$ (с первой ступени шары выбывают).

Определите победителя.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите `first` или `second`.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $0 \le x_i \le 10^9$

### Пример

Ввод:
```
3
0 2 1
```
Вывод:
```
first
```

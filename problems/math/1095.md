Вычислите $a^b \bmod (10^9 + 7)$.

### Формат ввода

Первая строка содержит $n$ — количество запросов.

Каждая из следующих $n$ строк содержит два целых числа $a$ и $b$.

### Формат вывода

Для каждого запроса выведите $a^b \bmod (10^9 + 7)$.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $0 \le a, b \le 10^9$

### Пример

Ввод:
```
2
3 4
2 8
```
Вывод:
```
81
256
```

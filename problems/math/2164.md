В задаче Иосифа $n$ человек стоят в кругу, и каждый второй выбывает, пока не останутся все. Дан запрос: каким по счёту выбывает человек с номером $k$?

### Формат ввода

Первая строка содержит $q$ — количество запросов.

Каждая из следующих $q$ строк содержит два числа $n$ и $k$.

### Формат вывода

Для каждого запроса выведите номер человека, выбывшего $k$-м.

### Ограничения

- $1 \le q \le 10^5$
- $1 \le k \le n \le 10^9$

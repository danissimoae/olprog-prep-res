Есть $n$ детей и $m$ яблок. Сколькими способами можно раздать яблоки детям (ребёнок может получить 0 или более яблок)?

### Формат ввода

Два числа $n$ и $m$.

### Формат вывода

Выведите количество способов по модулю $10^9 + 7$.

### Ограничения

- $1 \le n, m \le 10^6$

### Пример

Ввод:
```
3 2
```
Вывод:
```
6
```

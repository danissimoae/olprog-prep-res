Дана перестановка чисел от 1 до $n$. Найдите её номер в лексикографическом порядке среди всех перестановок.

### Формат ввода

Первая строка содержит $t$ — количество тестов.

Каждый тест: число $n$, затем перестановка из $n$ чисел.

### Формат вывода

Для каждого теста выведите номер перестановки (нумерация с 1) по модулю $10^9 + 7$.

### Ограничения

- $1 \le t \le 10^5$
- $1 \le n \le 2 \cdot 10^5$

### Пример

Ввод:
```
2
3
2 1 3
4
2 4 1 3
```
Вывод:
```
2
9
```

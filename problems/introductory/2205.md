Код Грея длины $n$ — это последовательность всех $2^n$ битовых строк длины $n$, где соседние строки отличаются ровно в одном бите.

Выведите код Грея длины $n$.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите $2^n$ строк — код Грея.

### Ограничения

- $1 \le n \le 16$

### Пример

Ввод:
```
2
```
Вывод:
```
00
01
11
10
```

Подсчитайте количество способов разместить 8 ферзей на шахматной доске $8 \times 8$ так, чтобы они не били друг друга и не стояли на занятых клетках.

### Формат ввода

8 строк по 8 символов: `.` — пустая клетка, `*` — занятая.

### Формат вывода

Выведите количество допустимых расстановок.

### Пример

Ввод:
```
........
........
..*.....
........
........
.....**.
....*...
........
```
Вывод:
```
65
```

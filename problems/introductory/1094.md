Дан массив из $n$ целых чисел. На каждом шаге вы можете увеличить любой элемент на 1. Какое минимальное количество операций нужно, чтобы массив стал возрастающим?

### Формат ввода

Первая строка содержит целое число $n$. Вторая строка содержит $n$ целых чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите минимальное количество операций.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
5
3 2 5 1 7
```
Вывод:
```
5
```

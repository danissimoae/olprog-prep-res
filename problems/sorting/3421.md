Дан массив из $n$ целых чисел. Подсчитайте количество подпоследовательностей (не обязательно непрерывных), в которых все элементы различны.

Результат выведите по модулю $10^9 + 7$.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите количество подпоследовательностей с различными элементами по модулю $10^9+7$.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

Дан массив из $n$ целых чисел. Разделите его на $k$ подряд идущих частей так, чтобы максимальная сумма части была минимальной.

### Формат ввода

Первая строка содержит $n$ и $k$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите минимально возможную максимальную сумму части.

### Ограничения

- $1 \le k \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
5 3
2 4 7 3 5
```
Вывод:
```
8
```

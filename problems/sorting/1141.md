Дан список песен в плейлисте. Какова максимальная длина последовательности подряд идущих песен, в которой каждая песня уникальна?

### Формат ввода

Первая строка содержит одно целое число $n$ — количество песен.

Вторая строка содержит $n$ целых чисел $k_1, k_2, \dots, k_n$ — идентификаторы песен.

### Формат вывода

Выведите максимальную длину последовательности уникальных песен.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le k_i \le 10^9$

### Пример

Ввод:
```
8
1 2 1 3 2 7 4 2
```
Вывод:
```
5
```

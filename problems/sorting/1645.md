Дан массив из $n$ целых чисел. Для каждого элемента найдите индекс ближайшего слева элемента, меньшего его.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите $n$ чисел: для каждого элемента — индекс ближайшего меньшего слева (нумерация с 1), или 0, если такого нет.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
8
2 5 1 4 8 3 2 5
```
Вывод:
```
0 1 0 3 4 3 3 7
```

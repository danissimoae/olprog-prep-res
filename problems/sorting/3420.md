Дан массив из $n$ целых чисел. Подсчитайте количество подмассивов, в которых все элементы различны.

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит $n$ чисел $x_1, \dots, x_n$.

### Формат вывода

Выведите количество подмассивов с различными элементами.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
5
1 2 1 3 2
```
Вывод:
```
8
```

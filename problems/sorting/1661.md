Дан массив из $n$ положительных целых чисел. Ваша задача — подсчитать количество подмассивов с суммой, равной $x$.

### Формат ввода

Первая строка содержит два целых числа $n$ и $x$ — размер массива и целевая сумма.

Вторая строка содержит $n$ целых чисел $a_1, a_2, \dots, a_n$ — элементы массива.

### Формат вывода

Выведите количество подмассивов с суммой $x$.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x, a_i \le 10^9$

### Пример

Ввод:
```
5 7
2 4 1 2 7
```
Вывод:
```
3
```

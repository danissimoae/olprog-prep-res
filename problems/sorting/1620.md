На фабрике есть $n$ станков, станок $i$ производит одну деталь за $k_i$ времени. За какое минимальное время можно произвести $t$ деталей?

### Формат ввода

Первая строка содержит $n$ и $t$.

Вторая строка содержит $n$ чисел $k_1, \dots, k_n$ — время производства одной детали на каждом станке.

### Формат вывода

Выведите минимальное время производства $t$ деталей.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le t, k_i \le 10^9$

### Пример

Ввод:
```
3 7
3 2 5
```
Вывод:
```
8
```

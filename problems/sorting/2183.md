У вас есть $n$ монет с положительными значениями. Какова минимальная сумма денег, которую вы не можете создать, используя эти монеты?

### Формат ввода

Первая строка содержит одно целое число $n$ — количество монет.

Вторая строка содержит $n$ целых чисел $x_1, x_2, \dots, x_n$ — значения монет.

### Формат вывода

Выведите минимальную сумму, которую невозможно создать.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
5
2 9 1 2 7
```
Вывод:
```
6
```

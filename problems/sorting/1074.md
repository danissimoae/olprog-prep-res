Есть $n$ палочек с заданными длинами. Ваша задача — изменить их длины так, чтобы все они стали одинаковыми.

Стоимость изменения длины одной палочки на единицу — 1. Какова минимальная общая стоимость?

### Формат ввода

Первая строка содержит одно целое число $n$ — количество палочек.

Вторая строка содержит $n$ целых чисел $p_1, p_2, \dots, p_n$ — длины палочек.

### Формат вывода

Выведите одно число — минимальную стоимость.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le p_i \le 10^9$

### Пример

Ввод:
```
5
2 3 1 5 2
```
Вывод:
```
5
```

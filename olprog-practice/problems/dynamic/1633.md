Подсчитайте количество способов получить сумму $n$, бросая кубик один или несколько раз. На каждом броске выпадает число от 1 до 6.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите количество способов по модулю $10^9 + 7$.

### Ограничения

- $1 \le n \le 10^6$

### Пример

Ввод:
```
3
```
Вывод:
```
4
```

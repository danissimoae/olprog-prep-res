Дан массив из $n$ целых чисел. Найдите количество различных чисел в массиве.

### Формат ввода

Первая строка содержит одно целое число $n$ — размер массива.

Вторая строка содержит $n$ целых чисел $x_1, x_2, \dots, x_n$.

### Формат вывода

Выведите одно число — количество различных чисел.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$

### Пример

Ввод:
```
5
2 3 2 2 3
```
Вывод:
```
2
```

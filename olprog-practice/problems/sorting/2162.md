Дети стоят в кругу и выбывают по счету: начиная с первого, каждый второй ребенок выходит из круга, пока не останется один.

Выведите порядок, в котором дети выходят.

### Формат ввода

Одно целое число $n$ — количество детей.

### Формат вывода

Выведите $n$ чисел — порядок выбывания.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$

### Пример

Ввод:
```
7
```
Вывод:
```
2 4 6 1 5 3 7
```

Дано $n$ отрезков. Для каждого отрезка определите, содержит ли его какой-то другой отрезок, и содержит ли он сам какой-то другой отрезок.

Отрезок $[a, b]$ содержит отрезок $[c, d]$, если $a \le c$ и $d \le b$.

### Формат ввода

Первая строка содержит $n$.

Каждая из следующих $n$ строк содержит два числа $x$ и $y$ — концы отрезка.

### Формат вывода

Выведите две строки по $n$ чисел: в первой — 1 если этот отрезок содержится в другом, иначе 0; во второй — 1 если он содержит другой, иначе 0.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $1 \le x < y \le 10^9$

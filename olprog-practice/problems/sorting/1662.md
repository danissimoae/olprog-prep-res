Дан массив из $n$ целых чисел. Ваша задача — подсчитать количество подмассивов, где сумма значений делится на $n$.

### Формат ввода

Первая строка содержит одно целое число $n$ — размер массива.

Вторая строка содержит $n$ целых чисел $a_1, a_2, \dots, a_n$ — элементы массива.

### Формат вывода

Выведите количество подмассивов с суммой, кратной $n$.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$
- $-10^9 \le a_i \le 10^9$

### Пример

Ввод:
```
5
3 1 2 7 4
```
Вывод:
```
1
```

Дан массив, содержащий каждое число от 1 до $n$ ровно один раз. Вы можете проходить массив слева направо и собирать числа по порядку.

Сколько раз вам нужно будет пройти массив, чтобы собрать все числа?

### Формат ввода

Первая строка содержит одно целое число $n$ — размер массива.

Вторая строка содержит $n$ целых чисел $x_1, x_2, \dots, x_n$ — перестановку чисел от 1 до $n$.

### Формат вывода

Выведите количество проходов.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$

### Пример

Ввод:
```
5
4 2 1 5 3
```
Вывод:
```
3
```

Пояснение: сначала собираем 1, затем 2, потом нужен новый проход для 3, затем для 4, и 5 собирается в том же проходе что и 4.

Дано положительное целое число $n$. Ваша задача — выполнить следующий алгоритм:

- Если $n = 1$, остановиться
- Если $n$ четное, разделить его на 2
- Если $n$ нечетное, умножить его на 3 и прибавить 1

Выведите все числа, которые появятся в процессе выполнения алгоритма.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите все числа в одной строке через пробел.

### Ограничения

- $1 \le n \le 10^6$

### Пример

Ввод:
```
3
```
Вывод:
```
3 10 5 16 8 4 2 1
```

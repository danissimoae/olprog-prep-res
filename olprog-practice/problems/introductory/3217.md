Дана шахматная доска $n \times n$. Конь стартует в клетке $(0, 0)$. Для каждой клетки определите минимальное число ходов коня, чтобы её достичь.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Выведите $n$ строк по $n$ чисел — минимальное количество ходов до каждой клетки.

### Ограничения

- $5 \le n \le 1000$

У вас есть числа от 1 до $n$. Ваша задача — разделить их на два множества с равной суммой.

### Формат ввода

Одно целое число $n$.

### Формат вывода

Если невозможно, выведите `NO`. Иначе выведите `YES`, затем два множества: сначала размер и элементы первого, затем размер и элементы второго.

### Ограничения

- $1 \le n \le 10^6$

### Пример

Ввод:
```
7
```
Вывод:
```
YES
4
1 2 4 7
3
3 5 6
```

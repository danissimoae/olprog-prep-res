Даны $k$ простых чисел. Подсчитайте количество чисел от 1 до $n$, которые делятся хотя бы на одно из этих простых чисел.

### Формат ввода

Первая строка содержит $n$ и $k$.

Вторая строка содержит $k$ различных простых чисел.

### Формат вывода

Выведите количество таких чисел.

### Ограничения

- $1 \le n \le 10^{18}$
- $1 \le k \le 20$

### Пример

Ввод:
```
20 2
2 5
```
Вывод:
```
12
```

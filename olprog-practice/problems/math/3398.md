Дана перестановка. Применяя её к самой себе, получаются раунды. Сколько раундов нужно, чтобы вернуться к начальной перестановке?

### Формат ввода

Первая строка содержит $n$.

Вторая строка содержит перестановку из $n$ чисел.

### Формат вывода

Выведите количество раундов по модулю $10^9 + 7$.

### Ограничения

- $1 \le n \le 2 \cdot 10^5$

### Пример

Ввод:
```
4
2 1 4 3
```
Вывод:
```
2
```
